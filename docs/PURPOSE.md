# Purpose of this repository

This repository serves as a **clean technical business card**.

- Academic review (Universidad de La Laguna context)
- LinkedIn / professional profile

## Design principles applied

1. **No secrets** — all credentials stripped from workflows.
2. **Importable** — every JSON can be loaded into a fresh n8n instance.
3. **Relevance** — focus on skills currently demanded:
   - n8n / Make-style orchestration
   - RAG (vector stores + embeddings + grounded LLM answers)
   - Multi-agent systems
   - Email / Telegram / Calendar integrations
   - Reliable automation patterns (backup, triage, voice)

4. **Neutral language** — English primary, professional tone, no internal R&D jargon.
