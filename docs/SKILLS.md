# Skills Mapping

Mapped to common Spanish job titles.

- n8n workflow design (CRM, DB, messengers, APIs)
- Webhooks, REST integrations
- Error handling and retries (in backup / agent flows)

## Arquitecto de Soluciones IA / AI Solutions Architect
- End-to-end system view (ingest → vector → LLM → action)
- Packaging automations for business impact (hours saved)

## Especialista en Integración de IA / RAG Specialist
- RAG setup: embeddings, vector store (Pinecone), document loaders
- Grounding answers on internal knowledge base

## Generative AI / Cloud DevOps (related)

- API token auth, key handling
