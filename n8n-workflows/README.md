# n8n Workflows

Sanitized, import-ready workflows. All credentials removed.

## How to import

1. Open your n8n instance
2. **Workflows** → **Import from File**
3. Choose any `*_clean.json`
4. Re-connect your own credentials (OpenAI / Gemini / Pinecone / Gmail / Telegram / Google Drive etc.)
5. Activate
